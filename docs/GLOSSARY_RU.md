# Глоссарий терминов (RU)

Канонический словарь для русификации базы упражнений. Источник истины для
`scripts/lib/` (движок перевода названий). При ручном ревью придерживайтесь
этих правил; при добавлении новых терминов — пополняйте словарь здесь и в
`scripts/lib/phrases.mjs` / `scripts/lib/words.mjs` / `scripts/lib/overrides.mjs`.

## Ключевые принципы

1. **Движение важнее снаряда.** «Deadlift» — не всегда «становая тяга»:
   румынская тяга (Romanian), сумо (Sumo), на прямых ногах (Stiff-legged),
   с дефицита (Deficit). Смотрите на модификатор.
2. **Row** зависит от контекста: тяга штанги в наклоне (Bent Over Barbell Row),
   тяга нижнего блока сидя (Seated Cable Row), тяга гантели в наклоне
   (Dumbbell Row), тяга к подбородку (Upright Row).
3. **Curl** = «сгибание»: на бицепс (снаряд + хват), ног (Leg Curl),
   запястий (Wrist Curl).
4. **Lunge** — выпад; Split Squat — сплит-присед (не то же самое);
   Walking Lunge — шагающие выпады.
5. **Press** зависит от положения: жим лёжа (Bench), жим над головой /
   армейский жим (Military/Standing Overhead), жим гантелей, жим ногами
   (Leg Press), швунг (Push Press).
6. **Алиасы обязательны**: в запись добавляются ё/е-варианты, разговорные
   сокращения («становая», «присед», «брусья») и английское название —
   поиск не должен зависеть от идеального написания.

## Чего избегать

- Кальки порядка слов («Штанга шраг» → «Шраги со штангой»).
- Дословного «толкать вниз» для pushdown, «завиток» для curl.
- Разных переводов одного термина в разных упражнениях — сначала глоссарий,
  потом название.
